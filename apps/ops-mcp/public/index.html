Fleet Ops MCP server

A Node.js MCP server that lets any AI assistant read live fleet telemetry, search service bulletins, and open work orders. Posit Connect hosts it, signs callers in, and controls who can use it.

.../mcp

TOOLS

Six tools, one governed endpoint

fleet_summary

Machines running, idle, and in alert, plus utilization.

find_machines

Filter the fleet by status, dealer, type, or region.

machine_detail

Live telemetry and active alerts for one machine.

search_service_bulletins

Find the fix, parts, and labor for a symptom or alert code.

list_work_orders

Open and recent service work orders.

create_work_order

Open a work order. It shows on the Ops Hub dashboard at once.
